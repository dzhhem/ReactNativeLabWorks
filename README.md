## Setup Instructions
1. Clone the repository
```bash
git clone https://github.com/vt231dmyu/MobileLabsRN2025
cd MobileLabsRN2025
```
2. Create and switch to a local branch `lab-3` based on the remote branch
```bash 
git checkout -b lab-3 origin/lab-3
```
3. Install dependencies
```bash
npm install --legacy-peer-deps
```
4. Start the project
```bash
npx expo start
```
5. Access the app (one of the options)
- Scan the QR code with your Expo Go app on your phone.
- Use an Android emulator/iOS simulator.
